
### 📊 Call Center Data Analysis – Excel Dashboard

## Overview
This project delivers an interactive **Call Center Performance Dashboard** built in **Microsoft Excel** to monitor operations, agent productivity, revenue, and customer satisfaction.  
It converts raw call data into clear, actionable insights for management.

## Key Metrics
- **Total Calls:** 1,000  
- **Total Revenue:** €96,623  
- **Total Duration:** 89,850  
- **Average Rating:** 3.9 / 5  
- **Happy Calls:** 307  

## Dashboard Highlights
- 📈 Monthly call trend analysis  
- 👩‍💼 Agent performance (calls & revenue)  
- 🌍 Regional comparison: Cincinnati, Cleveland, Columbus  
- 🚻 Female vs Male caller distribution  
- ⭐ Customer rating breakdown (1–5)  
- 📋 Detailed revenue table with conditional formatting  
- 🎛️ Representative slicer for interactive filtering  

## Tools Used
- Microsoft Excel  
- Pivot Tables & Pivot Charts  
- Slicers  
- Conditional Formatting  
- Excel formulas (IF, SUM, AVERAGE)  

## Dataset Fields
Call ID, Representative, City, Call Duration, Call Outcome, Amount (€), Customer Rating, Month.

## Key Insights
- R02 handled the highest call volume  
- Revenue is evenly distributed across agents  
- Ratings are predominantly **4–5**, indicating strong satisfaction  
- Peak call activity occurs in **Mar–Apr** and **Oct**

## How to Use
1. Open the Excel dashboard file  
2. Use the **Representative slicer** to filter data  
3. Review KPI cards for quick performance view  
4. Analyze charts for trends and comparisons
